# 书房 · 啃书流程

## 目录约定

每本书在 `Library/` 下占一个文件夹，结构固定：

```
Library/<书名>/
  00-原书/            # 按章切分后的原文 markdown：01-章名.md, 02-章名.md …
  01-全书梗概.md       # 一页纸：这本书讲什么、结构、适合怎么读
  02-逐章摘要.md       # 每章 3-8 句话的摘要，带 [[00-原书/NN-章名]] 链接
  glossary.md         # 译名表：原文 | 译名 | 首次出现章节 | 备注
  译文/               # 01-章名.md …（与 00-原书 同名对应）
  讨论/               # 按日期或主题存讨论记录
  笔记/               # 读书笔记
  原始文件.<ext>       # 用户给的原始文件，原样保留
```

书名文件夹用中文译名（没有通行译名就自己译一个简短的），不带特殊字符。

## 一、入库（用户丢文件进来 / 说要读某本书）

1. **收文件**：把用户给的文件移动到 `Library/<书名>/原始文件.<ext>`。
   - 用户说了文件名或大概位置但你第一眼没找到 → **先把整个书房根目录和 Library 都用 Glob 扫一遍**（`*.epub` `*.txt` `*.pdf` `*.docx` `*.md`），用户嘴里的「书库/根目录/文件夹里」可能指任何一层。扫到唯一候选就直接用它；有多个就列出来问是哪个。
   - 真的到处都没有 → 请用户把文件拖进对话或放到书房文件夹里，**不要**上网找书源。
2. **转 markdown**：
   - epub/docx/html → `pandoc -f <fmt> -t gfm --wrap=none`
   - txt/md → 直接用
   - pdf → 优先 `python -m pymupdf4llm`（装了的话），否则 pandoc 提取；扫描版 PDF 明确告知用户「这本是扫描图片，需要先 OCR，暂时处理不了」
3. **切章**：按目录/标题结构切成 `00-原书/NN-章名.md`。切完抽查 3 章开头结尾与原文核对，确认没切丢内容。章节超过 50 个时按「部/卷」建子文件夹。
4. **梳理**：
   - `01-全书梗概.md`：书讲什么、作者背景一句话、全书结构（几部分各讲什么）、建议阅读顺序。
   - `02-逐章摘要.md`：逐章 3-8 句。**摘要基于每章真实内容**——逐章打开文件读，禁止只看目录猜。长书可以分批做，每批完成后告诉用户进度。
   - `glossary.md`：初始化，把书里的主要人名/地名/术语先收 20-50 条，给出拟定译名。
5. **汇报**：告诉用户书入库了，梗概和摘要在哪，问要不要开始翻译（以及从哪章开始）。

## 二、翻译（「翻第 N 章」「N 到 M 章」「全部」）

1. 打开 `00-原书/NN-章名.md` 原文 + `glossary.md`。
2. **逐段对照翻译**，写到 `译文/NN-章名.md`。规则：
   - 目标语言默认简体中文，语体跟原书体裁走（小说译得像小说，学术书译得像学术书）。
   - 专有名词先查 glossary；表里没有的，翻译时定一个译名**并同步补进 glossary**（写明首次出现章节）。全书同一名词绝不许出现两种译法。
   - 保留原文的标题层级、脚注、引用块结构。
   - 译文文件开头加一行元信息：`> 原文：[[../00-原书/NN-章名]] · 译于 <日期>`
   - 疑难句在句后加译注 `（译注：…）`，拿不准的标 `【存疑：原文 "..."】`，不要硬编。
3. **长章分段**：超过 3000 词的章切成几段，一段一段译完拼合，避免中间漏段。译完通读一遍查连贯。
4. **批量模式**（范围/全部）：逐章执行上面的流程，每译完一章报一次进度（「第 5 章完成，还剩 3 章」）。批量前先告诉用户预计要多久，长任务建议用户先去干别的。
5. 译完更新 `02-逐章摘要.md` 里该章的条目，加 ✅ 已翻译 标记和 [[译文/NN-章名]] 链接。

## 三、讨论与笔记

- 用户问书的内容：先查本地文件（摘要 → 相关章原文/译文），基于文件回答，标注出处章节。本地没有的内容如实说没有，可以联网查作者/背景/评论，但书的正文永远以本地文件为准。
- 有价值的讨论（用户明显在思考、或聊了 5 轮以上的主题）：主动问用户「要不要把这段讨论存下来」，存到 `讨论/<日期>-<主题>.md`。
- 用户口述的感想/想法：整理成 `笔记/<主题>.md`，用用户的原意，不要过度加工。

## 通用规则

- 每完成一个大动作（入库完成、一章翻完、批量完成）都用一两句人话汇报，别刷屏。
- 千万不要在没有原文文件的情况下「翻译」——那是编造。文件缺了就直说。
- pandoc/python 不在时：告知用户「安装好像缺了东西」，建议重跑安装器，不要贴命令行报错。
