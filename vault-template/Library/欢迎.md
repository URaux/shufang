# 欢迎来到群星阅览室 📚

这里以后每本书一个文件夹。现在还是空的。

## 怎么开始

1. 双击桌面的「启动群星阅览室」。
2. 在打开的网页里（或者 Obsidian 右侧的聊天窗格里）把书的文件拖进去，或者直接说「我想读某某书，文件在桌面上」。
3. 助手会自动整理出全书梗概和逐章摘要。
4. 想看哪章就说「翻第几章」，翻好的译文会出现在这本书的「译文」文件夹里。

## 每本书长这样

- `01-全书梗概` — 一页纸看懂这本书
- `02-逐章摘要` — 每章几句话，帮你决定读哪章
- `译文/` — 翻好的章节
- `讨论/` 和 `笔记/` — 你和助手聊出来的东西

手机上也能用：电脑开着「群星阅览室」时，手机浏览器打开启动窗口里显示的那个网址就行（要连同一个 Wi-Fi）。
