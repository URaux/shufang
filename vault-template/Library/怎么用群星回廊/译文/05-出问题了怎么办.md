# 5 · 出问题了怎么办

## 先试这两下

- 网页打不开：看黑窗口是不是关了。关了就重新双击桌面「启动群星回廊」。
- 聊天没反应：去 ⚙ 设置看 API key 配了没、有没有余额。

## 还不行，把日志发给站长

三个地方都能一键复制，挑一个顺手的：

1. 网页里：⚙ 设置 → 最底下「复制诊断日志」（也能「导出成文件」，手机上更省事）。
2. 桌面上：双击「复制群星回廊日志」。
3. 安装的时候出错：它已经自动复制好了，直接粘贴。

复制出来的内容不含你的 key 和口令，放心发。日志里有一段「读书的工具链」，
写着这台电脑上 Python 是哪个版本、各个组件在不在——站长看一眼就知道哪一环断了。

## 一、聊天相关

**助手一直在转，停不下来。**
发送键在它写字的时候会变成「停下」，点一下就掐掉。回车不会停——那是留给你
一边等一边把下一句敲好的。

**聊天说「助手没回应」。**
先看设置页里的 key 和余额。都正常的话，多半是网络抖了一下，把刚才那句再发一遍。
一直不行就关掉程序、重新双击桌面图标（顺便会自动更新到最新版）。

**说「这次要交代给助手的话太长了」。**
你选的大脑是「自定义命令」或者 DeepSeek 官方助手，而 Windows 的命令行有长度上限。
两个办法：去设置页把大脑换回「内置助手」（它没有这个限制），或者一次少翻几章。

**几段对话串台了。**
新版本已经修好：每段对话、每本书各有各的上下文，互不干扰。如果你的还串，
说明程序没更新——关掉再双击一次桌面图标。

---

## 二、PDF 和扫描版的书

**「这本是扫描图片，要先做文字识别才能读」。**
这本书里没有可选中的文字，每一页都是图片，得先认字。
去 ⚙ 设置，找到「读书的工具」那一格，点「试着修一下：读扫描版（认字）」。
那一格只在缺东西的时候才出现；没看到它，就说明认字组件是好的，问题在别处。

**「PDF 组件装上了但跑不起来」。**
同上，去设置页那一格点「试着修一下：读 PDF」。它会把安装时那几条命令原样再跑一次
——十有八九是当时网没通。修不好的话，屏幕上会直接把命令的原话摊出来，
截图发给站长就能定位。

**最常见的两个原因（修不好时对照看）：**

- **网没通**。国内直连 pip 的源经常被掐。换个时间再试，或者挂上代理再点一次。
- **缺「Microsoft Visual C++ 运行库」**。搜 `vc_redist.x64.exe` 装上，再点一次。

**认字组件对 Python 版本挑剔。**
它目前最高只支持到 Python 3.12。如果你这台是 3.13 或者 3.14，它装不上去，
不是你哪里选错了。去 python.org 另外装一个 3.12（两个版本可以共存），
再重跑一次安装器就行。设置页那一格会直接告诉你这台是什么版本。

**读扫描版特别慢。**
一页几秒是正常的，三百页大约五到十分钟。进度条上会写「正在认字 42/300 页」。

**外文的扫描书认得乱七八糟（重音符号全没了、俄语变成一串拉丁字母）。**
传书的时候选一下这本书是什么语言，它会去下对应的认字模型。
或者在对话里直接说一句「这是法语书」。

## 三、插图

**书里的图没提取出来。**
纯扫描件（整页都是图）我们不抽图——抽出来的是一堆页面截图，没有意义。
有文字层的 PDF、epub、docx 都会抽。

**助手看不懂图里画的是什么。**
它本来就看不见。去 ⚙ 设置 →「读图」，填一个会看图的模型，
以后传进来的书每张图都会被看一遍，说明写在图旁边。已经在架上的书，
去那本书左边侧栏点「读一遍插图」补上。这一步要额外花钱，所以默认是关的。

## 四、安装和更新

**安装时下载失败。**
多半是网络。换个时间重跑安装器，它会自己换国内的源。

**装完想读 PDF，但当时跳过了那一步。**
重跑一次安装器就行，你的书和译文一个字都不会动。

**怎么更新。**
关掉群星回廊，再双击一次桌面上的「启动群星回廊」，它自己会更新。
书和译文不动。设置页里也有一颗「更新并重启」。

**更新了但新功能没出现。**
自动更新只换程序本身，不换底下的运行环境（Python、认字组件那些）。
跟安装有关的改动，要重跑一次安装器才拿得到。

## 五、手机和远程

**手机打不开链接。**
手机和电脑是不是同一个 Wi-Fi？公司和学校的 Wi-Fi 常常把设备互相隔开，
回家再试，或者按第 4 篇装 Tailscale。

**换了 Wi-Fi 之后链接失效。**
局域网地址会变。回设置页重新复制一次链接。
