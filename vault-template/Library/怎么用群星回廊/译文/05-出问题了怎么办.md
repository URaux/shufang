# 5 · 出问题了怎么办

## 先试这两下

- 网页打不开：看黑窗口是不是关了。关了就重新双击桌面「启动群星回廊」。
- 聊天没反应：去 ⚙ 设置看 API key 配了没、有没有余额。

## 还不行，把日志发给站长

三个地方都能一键复制，挑一个顺手的：

1. 网页里：⚙ 设置 → 最底下「复制诊断日志」。
2. 桌面上：双击「复制群星回廊日志」。
3. 安装的时候出错：它已经自动复制好了，直接粘贴。

复制出来的内容不含你的 key 和口令，放心发。

## 常见的几个

- **安装时下载失败**：多半是网络。换个时间重跑安装器，它会自己换国内的源。
- **手机打不开链接**：手机和电脑是不是同一个 Wi-Fi？公司 Wi-Fi 常常隔开设备，回家再试，或者用第 4 篇的办法。
- **读 pdf 特别慢**：扫描版要先认字，一页几秒，正常。
