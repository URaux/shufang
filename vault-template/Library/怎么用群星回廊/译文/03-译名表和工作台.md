# 3 · 译名表和工作台

顶栏的「工作台」有两格，外加一个默认关着的实验功能。

## 术语表

每本书一张表：人名、地名、术语，原文对应译名。翻译的时候它会照着这张表来，所以全书一个人不会出现两个名字。

标红的是它自己也拿不准的，点一下就能定。改一处，下次翻译就照新的来；「把 N 处 X 统一成 Y」一个按钮把已经翻好的也改掉。

「体系」是领域通行的译法（比如古希腊神名），从工坊装进来。它只是建议，你这本书自己定的译名比它大。

## 组件

站长做的小工具，装了才有。现在还空着——有新的会出现在这里，点「安装」就行。

## 门枢（实验功能，默认关着）

把站上的几个页面嵌进来看。还在试，所以默认不显示；想看的话去右上角 ⚙ 设置 →「实验功能」打开，工作台就多出这一格。
