# 1 · 把书放进来

## 两种放法

**拖。** 去「对话」，把文件拖到聊天框里松手。

**说。** 在聊天框里打一句：「桌面上有本 The Stranger.epub，我想读」。它自己会去找。

支持 epub、pdf、txt、docx。扫描版的 pdf 也行，但要慢得多——它得先认字。

## 放进去之后会发生什么

它先把书按章切开，再写一份「全书梗概」和一份「逐章摘要」。几分钟到十几分钟，看书的厚度。

这期间你可以关掉网页去干别的，黑窗口别关就行。回来的时候书架上就有它了。

## 放进去的书在哪

「文档 / 书房 / Library / 书名」这个文件夹里。原文件也在，没动过。

不想要这本书了，把这个文件夹删掉就行。
